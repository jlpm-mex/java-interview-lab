# Java Interview Lab

A collection of Java coding exercises focused on data structures, algorithms, problem-solving, and software engineering fundamentals.

## Goals

Strengthen problem-solving and algorithmic reasoning.

Practice selecting appropriate data structures.

Analyze time and space complexity.

Write clean, testable Java code.

Validate solutions with automated tests.
